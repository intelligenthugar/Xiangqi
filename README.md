# 中國象棋｜Xiangqi v46

這是可部署到 GitHub Pages 的靜態中國象棋網站，包含首頁、棋盤、管理員頁面與前端程式。

## 檔案結構

```text
index.html
chess.html
admin.html
css/style.css
js/chess.js
js/home.js
README.md
```

## 部署方式

1. 解壓縮 ZIP。
2. 將檔案上傳到 GitHub Pages 儲存庫對應位置，覆蓋同名檔案。
3. **保留你原本的 `js/firebase-config.js`**；此 ZIP 不包含 Firebase 設定檔。
4. 等待 GitHub Pages 更新後，在瀏覽器按 `Ctrl + F5` 強制重新整理。

## 重來按鈕（v46）

- **單機版：** 按「重來」會先詢問是否確定重置目前棋局；取消則保留目前局面。
- **積分排位賽：** 按「重來」會先顯示確認提示，明確告知超過 5 步後重來會判定本局認輸。
- 排位賽未超過 5 步時，確認後會重新開始；超過 5 步且對局尚未結束時，確認後判定認輸，不會重置以逃避敗局。
- 已結束的排位賽可以確認後開始新局。
- 連線對戰仍依原本規則處理，不能在進行中直接重來。

## 主要功能

- 單機 AI 對戰與同裝置雙人對戰。
- 積分排位賽、排行榜及帳號功能（需要自行設定 Firebase）。
- 多人連線房間（需要 Firebase Realtime Database 設定與相符的安全規則）。
- 深色／淺色主題與行動裝置版面。

## 注意事項

- 此 ZIP 不含 `js/firebase-config.js`，請使用自己的 Firebase 設定檔。
- 只完成程式碼及靜態檔案檢查，未在此環境中實際連接 Firebase 或完成完整瀏覽器對戰測試。
- 排位賽前端提示不能單獨防止使用者竄改客戶端程式；若要防作弊，需另行設計伺服器端驗證。
