# 象棋 AI 助手

一個用 Python 寫的桌面小程式，搭配我的象棋網站使用：自動幫我下棋、在網頁上標示最佳走法，或是連續刷排位分數。
棋力來自內建的象棋引擎（也可以選用 Pikafish），畫面是一個深色的圖形視窗。

> 網站：<https://intelligenthugar.github.io/Xiangqi/chess.html>
> 這個程式是**個人使用**，不要放上網站或 GitHub（見最下面的「注意事項」）。

---

## 功能

| 功能 | 說明 |
|---|---|
| 三種模式 | 連線對打、單機（對網站 AI）、排位賽 |
| 自動下棋 | 輪到我就自動算棋、自動點棋盤走子 |
| 輔助模式 | 不幫我走，只在網頁上用綠圈／金色虛線圈標示建議走法 |
| 連續刷分 | 排位賽專用，一局接一局自動打，按取消後打完這局就停 |
| 擬真設定 | 第一步走常見開局、前幾步不動兵卒、每步隨機停頓，看起來像真人 |
| 即時棋盤 | 視窗左邊鏡像目前棋局，金色箭頭是引擎選的走法 |
| 瀏覽器常駐 | 程式關掉後 Chrome 不會跟著關，可以繼續截圖 |

## 環境需求

- Windows、macOS 或 Linux（以下以 Windows 為例）
- Python 3.9 以上（tkinter 是 Python 內建的，不用另外裝）
- Google Chrome
- Python 套件：`selenium`

## 安裝

1. 安裝 Python（<https://www.python.org>），安裝時**勾選「Add python.exe to PATH」**。
2. 開啟終端機，進入程式資料夾，安裝 Selenium：

   ```
   py -m pip install selenium
   ```

   > Windows 如果輸入 `python` 出現「Python was not found」，是被 Microsoft Store 的捷徑擋住了，
   > 把所有指令的 `python` 換成 `py` 就可以。

3. 測試引擎有沒有正常（不會開視窗）：

   ```
   py xiangqi_bot.py --test
   ```

   看到三行 `perft` 都顯示 `OK`，最後印出一步棋，就代表正常。

## 啟動

```
py xiangqi_bot.py
```

會跳出圖形視窗。

## 基本流程

1. 右上角選**模式**（連線對打／單機／排位賽），按 **開啟瀏覽器**。
2. 在跳出的 Chrome 裡**自己登入**、開好棋盤（連線模式就建立或加入房間）。
   - 登入狀態會被記住，只需要登入一次。
   - 連線模式可以用視窗裡的「連線大廳自動填寫」輸入暱稱、房間代碼，再按「送出」。
3. 選**引擎**與設定（見下方）。
4. 按 **▶ 開始下棋**。
5. 想暫停就按 **■ 暫停**。

一局結束後，視窗會顯示結果；你在網頁開新的一局，程式會自動偵測並繼續。

### 單機與排位賽的規則

玩家固定是紅方，網站 AI 是黑方。如果擲硬幣是黑方先手，程式會等網站 AI 走完再出手。

## 輔助模式

控制區選「**輔助模式（只在網頁標示建議）**」再按開始。

- 輪到我時，網頁上會出現：
  - **綠色實線框**：要動的棋子
  - **金色閃爍虛線框**：目的地
  - 右上角小框：建議走法、搜尋深度、評分
- 程式**不會**幫我走，我自己在網頁上動手。
- 輪到對手時標示會自動消失。

標示畫在 Bot 開的那個 Chrome 裡，所以要用那個視窗下棋。

## 連續刷分（排位賽）

切到「排位賽」模式時，控制區會出現橘色的 **🔁 連續刷分** 按鈕。

1. 先「開啟瀏覽器」，登入並進入排位賽。
2. 按 **🔁 連續刷分**，程式會一局接一局自動打：每局結束後等 2.5 秒讓積分寫完，再自動開下一局。
3. 按鈕會變成 **⏹ 取消刷分（打完這局後停止）**。按下去後，程式把目前這局打完就停止，
   然後**重新整理網站**即可。
4. 資訊欄會顯示「局數」與「勝場」。

刷分時為了加快速度，會自動跳過擬真停頓，每步思考時間最多 1.5 秒。

## 設定說明

| 設定 | 說明 |
|---|---|
| 引擎 | 「內建引擎」是預設；「Pikafish」是選用的外部引擎，更強（見下方） |
| 思考秒數 | 每步思考時間 1–15 秒，越久通常越強 |
| 前 N 步不動兵卒 | 預設 6。第一步會從常見開局（當頭炮、起馬、飛相、屏風馬…）隨機挑一個 |
| 停頓 | 每步出手前隨機多等幾秒（預設 2–6 秒），避免太像程式 |
| 視窗置頂 | 讓視窗一直在最上層 |

設定會自動存進 `bot_settings.json`，下次開啟會記住。

### 關於棋力

- 內建引擎：搜尋用 alpha-beta、迭代加深、置換表等技巧，每步 3 秒約可算 5～6 層。
- 想更強可以選用 **Pikafish**（免費的開源象棋引擎）：下載後在視窗按「瀏覽…」選它的 exe，
  同一資料夾要放它的 `.nnue` 檔。不選就完全不會用到。

## 常見問題

**`python` 找不到** → 改用 `py`（見「安裝」第 2 點）。

**開啟瀏覽器失敗** → 上一次 Bot 開的 Chrome 還開著。因為同一個設定檔同一時間只能被一個 Chrome 使用，
把舊視窗關掉再按「開啟瀏覽器」。

**連線模式看不到日誌** → 右邊面板可以用滑鼠滾輪或右側捲軸往下捲。

**對手離開房間** → 網站會跳出彈窗，程式會把內容印在日誌，並把彈窗留在畫面上讓你截圖；
你在網頁按確定後，程式會自動繼續監看。

**輪到我卻沒走棋** → 檢查：是否已登入、狀態燈是否顯示「等待開局」（擲硬幣中或雙方還沒準備好）、
是否選成了輔助模式。

**視窗太大或字太小** → 棋盤大小會依螢幕解析度與縮放比例自動調整；仍不合適的話，
調整 Windows 的「顯示縮放」。

- 若 Worker 無法使用，會自動退回舊版 AI，網站不會壞掉。

### 單機等級

「初級」與「中級」合併成 **新手**（看 2 步、偶爾亂走），「高級」改名為 **大師**（思考約 1.5 秒）。

### 排位段位

起始積分 1000。每個大段位分成 I、II、III 三小階。

| 段位 | 積分範圍 | 對手 AI | 勝／負基礎分 | 掉段 |
|---|---|---|---|---|
| 青銅 | 1000–1119 | 看 1 步，常失誤 | +30 / −5 | 不會 |
| 白銀 | 1120–1269 | 看 2 步，偶爾失誤 | +28 / −8 | 不會 |
| 黃金 | 1270–1449 | 看 3 步，很少失誤 | +26 / −10 | 不會 |
| 鑽石 | 1450–1689 | 看 4 步，不失誤 | +24 / −12 | 會 |
| 神話 | 1690–1989 | 思考 1 秒 | +22 / −14 | 會 |
| 傳奇 | 1990–2349 | 思考 2 秒 | +20 / −16 | 會 |
| 宗師 | 2350 以上 | 思考 3.5 秒 | +20 / −18 | 會 |

數字都集中在 `js/chess.js` 的 `RANK_TIERS`，可以直接調整。

### 技術加成（最高 +12）

只有**獲勝**（或和棋，最多 +6）才會加；輸棋不計技術加成。

| 項目 | 規則 |
|---|---|
| 吃子 | 每吃對方一子 +1，最多 +4 |
| 將軍 | 每將軍一次 +1，最多 +3 |
| 少失子 | 你被吃掉 ≤1 子 +3、≤3 子 +2、≤5 子 +1 |
| 速勝 | 雙方合計 40 手內獲勝 +2 |

- 排位賽面板會即時顯示「本局技術加成」目前累積了多少。
- 一局結束時，結果視窗會列出明細，例如：
  `排位 +38 分（基礎 +30，技術加成 +8：吃子 +3、將軍 +1、少失子 +3、速勝 +1）`。
- 速勝的手數門檻是 `chess.js` 裡的 `SKILL_FAST_PLIES`。

## 注意事項

- **不要把 Bot 放到 GitHub 或網站上。** `chrome_profile/` 裡有登入狀態，上傳等於把帳號交給別人；
  這個程式也是給自己用的。
- 程式靠網頁上的元素（棋盤格子、按鈕的 id 與 class）來讀棋盤和走子。
  如果之後大幅修改網站的 HTML 結構，Bot 可能要跟著調整。
- 前端的限制（鎖定難度、關閉網站等）不等於伺服器端的防護；
  網站的 README 也提醒過，正式的競技環境應該把積分驗證放在可信任的伺服器端。
